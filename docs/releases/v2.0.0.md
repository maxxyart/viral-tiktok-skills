# Viral Camp social analysis skills v2.0.0

Two updated skills for both Instagram Reels and TikTok:

- **Social Account Short Analysis (Viral Camp)** — reliable cohort metrics, comments, weighted/mean/median comment rates, publication-month tables and a concise HTML report.
- **Social Account Hook Analysis (Viral Camp)** — 60 recent videos by default, cover sheets of 20, exact original-language quotes, text × visual patterns, character roles, 1–2 references per formula and product-specific test recommendations.

Both packages are self-contained and support Claude Code, Codex and other SKILL.md agents. ScrapeCreators MCP is preferred; actual CLI/API transport is disclosed. The Python helper can replay MCP page exports offline.

## Download and install

Extract the desired ZIP into your agent's skills directory:

- Claude Code: `~/.claude/skills/`
- Codex: `~/.codex/skills/`

Python 3.10+ required; hook cover tooling additionally uses Pillow. No Gemini/xAI key required. See the repository README for ScrapeCreators access and complete usage instructions.

## Reliability changes

Timestamp sorting, ID deduplication, photo-post filtering, explicit partial-collection status, missing-value-aware math, unrounded baselines, strict annotation coverage, portable embedded-image HTML, and peak-plus-typical source references.

The skills distinguish cover evidence from observed video openings, exploratory ideas from repeated patterns, and publication-month cumulative views from actual monthly growth. The full method audit is in `docs/social-analysis-audit.md`.

## Compatibility

Replace old installed `tiktok-account-short-analysis` and `tiktok-account-hook-analysis` with the new `social-account-*` folders. Old implementations remain archived under `legacy/skills/`. The two carousel skills remain unchanged. Legacy npm commands are now named `legacy:short-analysis` and `legacy:hook-analysis`.

## Validation

15 offline behavior tests passed, both SKILL.md packages validated, and legacy TypeScript typecheck passed. The existing session's Instagram sample reproduced exactly. No fresh live TikTok account test was run. A GitHub Actions template is included but requires workflow-write access to activate.

Public feeds can omit pinned/private/deleted content. The report exposes these limitations and does not claim unrestricted account completeness.
